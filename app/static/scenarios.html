Każdy scenariusz tworzy świeżą sesję i sprawdza oczekiwane kody HTTP / pola. Ścieżki bramek nie wymagają żywego LLM.

S1: Bramka Pre-Lab

Wiadomość zablokowana → zła odpowiedź → dobra odpowiedź → czat odblokowany.

S2: SecurityGuard (Jailbreak)

Oczekuje message_id=blocked, tokens_used=0.

S3: PedagogyGates (kontekst pliku + gotowiec)

Odrzucenie pustego kontekstu oraz prośby o gotowy kod bez wywołania LLM.

S4: Frustration streak → Hints

Reveal zablokowany, potem zdarzenia IDE z polem type (z ~15 s cooldown anty-farming), potem hint odblokowany.

S5: Podsumowanie sesji

Sprawdza kształt odpowiedzi POST /summary.

S6: Blokada SSRF

Start z linkiem 127.0.0.1 → 400 ssrf_blocked.
